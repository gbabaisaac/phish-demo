# Phish demos

Static build of the Phish demo website: phishing simulation for AI coding-agent approvals.

**Live: https://gbabaisaac.github.io/phish-demo/**

- [Demo 1 · Pentest your reviewers](https://gbabaisaac.github.io/phish-demo/#/pentest): review a Codex-style session where some requests are planted. Reset any time.
- [Admin dashboard · seeded data](https://gbabaisaac.github.io/phish-demo/#/report): the reviewer pentest report after six weeks at a simulated Acme Corp.
- [Demo 2 · Review at machine speed](https://gbabaisaac.github.io/phish-demo/#/race): a person vs a prefix allowlist vs the Phish guard.

Built with `npm run build:site` from the Phish source repo; every number was computed by the product's own code.
